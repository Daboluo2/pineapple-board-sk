# 可编辑微型网页排版

默认交付自包含 HTML 文件，用户下载后用浏览器打开，无需安装或联网。托管与公开发布只在用户要求时另做。
使用 assets/editor-shell.html、editor.css、editor.js，经 scripts/build_editor.py 内嵌为独立网页；不引入外部脚本、遥测或上传服务。主题背景中不要烘焙方框；背景与图片、文字、必要细线分别保存。

## 1.1.2 形状与页面交互
左侧“形状”工具只负责绘制：顶部选矩形、椭圆、直线或更多类型，按下拖动时显示预览，松开后创建图层。单击画布不创建；按 V 或选“移动”工具后选择和移动已有图层。Shift 约束等宽高或线条 45° 方向，Alt 从中心绘制。验收须分别检查单击不新增图层、拖动可创建、工具切换和取消绘制。
新工作台采用 `schema: 2` 的 `pages`、`activePageId`；各页含 `id/title/width/height/background/nodes/guides`。旧版顶层 `width/height/nodes` 单页 JSON 可导入并转换。多页可保存在同一独立 HTML，不再沿用“一文件一页”的旧说明。

## 1.1.1 布局应用
按 [layout-principles.md](layout-principles.md) 组织展板内容。节点包围盒、选中框和示意图色块只用于定位，不应自动变成最终卡片底板；隐形网格、跨栏及非对称关系用现有坐标与图层表达。矩形节点可用于必要底色、图表或照片，不以形状数量判定布局好坏。本次只增强排版指导，不增加或声称编辑器具有新的路径、编组或自动构图能力。

## 项目模型与生成
建立 JSON：顶层 `id/title/schema/pages/activePageId`，尺寸、背景和节点置于各 `pages`；可选 `fontCss/fontFamily`。旧顶层 `width/height/background/nodes/decorations` 模型可作为构建输入或导入文件。
nodes 每项包含 id、kind、name、x/y/w/h（mm）。kind=text 时增加 text、fontSize（pt）、leading、weight、color；kind=image 时增加 data URI src 与 fit=contain/cover；kind 可选 rect、roundrect、ellipse、triangle、diamond、polygon、line、arrow；几何形状时增加 color，可选 strokeWidth/opacity。多边形 points 为相对区域的比例坐标数组；形状可设 stroke、strokeWidth、noFill、radius，所有元素可设 rotation、opacity、locked。
段落应是一个文字元素，而不是把每个字或每行拆成独立块。
图片和必要字体嵌入文件，不依赖失效路径；字体应覆盖全文，用户新增字符提供系统字体回退。必要框线使用独立 rect/line 节点，可删除，不烘焙进背景。
生成：`python scripts/build_editor.py project.json output.html`。输出应为自包含网页，不能留下外部 `editor.js` 或 `editor.css` 引用。
编辑器可改文字、字号、颜色、位置、尺寸、层级；可替换图片、撤销重做、保存 HTML、导入导出完整布局、导出 SVG、打印。主题装饰可隐藏。图像默认完整显示，避免拉伸。

## 保存与验收
浏览器暂存保留布局与可容纳的图片变更，空间不足或浏览器禁用时明确提示未暂存。任何跨设备保留与可靠备份都使用“保存网页”或导出完整布局；不把暂存当作可靠备份。
测试文字编辑、拖动、尺寸调整、替换图片、撤销重做、删除与层级、保存重开、JSON导入导出、SVG导出及打印隐藏编辑辅助层。渲染预览检查文字溢出与占位框。
确认打印物理尺寸与页面方向，关闭页眉页脚，选原始大小；浏览器打印结果未经实际PDF验证时，不声称已通过PDF输出验收。
本地交付网页按当前文件保存要求持久保存；技能模板本身通过技能更新保存，不重复作为用户文件上传。

## ③示意图也使用编辑器
初始图区、文字区、标题区各用简单色块划定，不在画布生成说明文字。编辑工具栏可有正常文字。提供八种几何形状，用户可自由增删改形、调整位置尺寸和颜色。圆形使用等宽高椭圆；多边形顶点可通过布局 JSON 修改。辅助网格与选中框不导出或打印。用户改动后将保存网页/布局作为新的③位置依据，重新检查文字空间，不强制恢复旧布局。

## 接续与当前边界
多页项目可用同一 HTML 的页签管理，统一风格与编号。用户修改后提供保存HTML或布局JSON，读取最新文件再生成预览和布局版本，不假称能自动观察用户本地浏览器。
可用的自由编辑包括单元素操作、多选编组、复制与层级；不宣称已有画布内多边形顶点编辑、任意路径节点拖拽、专业印前色彩管理或协同编辑。只按用户需要扩展，不为了“上线”额外增加复杂功能。

## 1.1 结构化审查与兼容性
- 输出为可编辑模型而非仅静态位图；需要整体预览时另导出预览，不能把最终确认的编辑结构替换为单张生图。
- 对锁定/冻结区域的精确需求，优先保留原图或锁定相应模型节点，使用独立图层替换；HTML编辑器的锁定仅保护部分操作，不等于禁止所有删除、替换或改变画面，任务流程仍需检查。
- 输出前检查模型中的图片data URI是否真实嵌入、字体是否可用、文字是否溢出、物理画幅是否正确，以及是否为原生清晰度。工具未核验时不得声称“所有浏览器均通过”。
- 1.1.2 增加同文件多页编辑，不增加网络访问、遥测或云端服务。旧版布局JSON依旧可导入；项目状态字段不强制写入旧版JSON。
