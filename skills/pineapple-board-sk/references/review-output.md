# 图片审查与输出验收

## 生成前必须核实的授权（优先于输出后验收）
检查本轮是否已向用户逐项展示待执行的参考图清单、正面提示词、负面提示词和英文补充提示词，且用户已针对该具体Prompt作出明确确认；单纯阶段确认无效。若Prompt更新或参考图变更，旧确认失效。未满足条件则禁止调用图像生成或编辑工具；只能停下输出待审稿内容。此项不与图像输出后的清晰度、结构验收合并，属于独立的执行授权检查。

## 每次审查
先读取图片，不以提示词代替结果检查。按以下顺序简明输出：
1. 已正确的部分；2. 最大问题；3. 小修或重做及依据；4. 具体修改；5. 需要时提供三段式修改Prompt。
不为凑检查项而虚构问题。优先解决影响叙事、数据、主体及母版适配的问题。

## 模块检查
- 内容：缺失、重复、事件因果、场景一致性、技术范围。
- 风格：颜色、图像处理、线条、强调色含义是否继承。
- 适配：目标区域尺寸、主体比例、留白、裁切安全区、相邻关系。
- 文字：小字、假字、错误标题是否清除；后期文字是否仍有足够空间。
- 图像：人物肢体、设备形态、透视、重复物体、错误结构。
- 数据：生成图是否暗含假比例或虚假结论。

## 1.1.1 排版专项检查
按 [layout-principles.md](layout-principles.md) 核对信息层级、网格与构图、留白分组、图文任务、字体色彩、内容适配和输出；通过缩略图、阅读顺序、实际尺寸与图文对应分别检查。删除边框不等于排版通过，必要矩形也不自动判失败。发现等权堆叠、主次混乱或拥挤时回到内容和布局修正，不强行增加曲线、异形或装饰。记录检查方式及未测试项，不重复推翻已经通过且未受变更影响的维度。

## 拼版验证
将实际模块置入母版，不只凭单图判断。渲染整页及关键局部，按最终物理尺寸检查。
记录使用版本、区域、缩放、裁切、文本字号和实际验证结果。
没有完成拼版或实际尺寸检查时标为“待适配/待验收”。
发现空间不足优先删冗余和调整构图；重大布局变动遵守用户确认方式。

## 输出
以用户/比赛/印厂要求为准。未知时明确暂定要求，不自称满足未读过的比赛规范。
核对物理尺寸、方向、页数、色彩要求、出血、文件格式、字体与图片有效分辨率。
有效ppi = 图片在最终布局中使用的像素数 / 对应英寸长度；裁切后按实际使用像素计算。
A3横版420×297 mm在300 ppi下约4961×3508像素；600ppi下约9921×7016像素（竖版对调宽高）；这是可计算的目标，不是原图自动具备的细节。**母版生成优先调用可用的 image/image_gen 能力并选择工具实际支持、符合要求画幅比例的最高原生分辨率与质量档位**；逐项记录实际原生宽高、最终目标尺寸与有效PPI，明确区分原生生成、矢量重建及放大重采样。若生图原生像素达不到目标，应保留矢量标题/文字/技术线和分层高清资产；必要时直说当前无法达到指定原生印刷细节，不以只改DPI元数据冒充合格。
放大或导出PDF不会增加真实细节。不因容器格式是PDF就称为高清或矢量。
不统一强制CMYK或出血，按接收方要求处理。字体嵌入/替换后重新渲染检查。
检查图表数字、基数、顺序、编号和来源；将目标值与实测分开。

## 完成状态
- Prompt完成：三段式提示词完整可用。
- 素材完成：图像审查通过，不代表拼版通过。
- 排版完成：实际素材及编辑文字已拼入最终页面。
- 输出检查通过：最终文件成功打开、渲染并符合已知规格。
报告剩余限制；不将计划输出当作交付完成。

## 母版审查的职责
除视觉品质外必须先核对是否实际使用了可用的 image/image_gen 图像生成能力（若未使用，说明替代工具及原因）、最高可用原生像素/质量档位是否被实际选择，记录输出像素并按版面尺寸计算有效PPI；不将低像素预览或简单重采样文件判为符合高清母版要求。
先判断是否好看，再检查主题识别、背景图、装饰图、装饰线条、焦点、层级和文字干扰。
不把仅有方框与分隔线的空白图当作成功视觉母版。
几何示意图管理精确位置，母版管理风格；不逐毫米否决母版，也不允许母版吞掉文字区。
图文试排使用真实文案和实际字号；过量文字应被识别为溢出，不能默默缩字号。
最终布局回到示意图，母版是视觉参考；必要时提取背景/装饰，不整页重生成替代排版。

## 无框与编辑验收
检查母版烘焙占位框、素材硬边、逐模块矩形底板三个来源；默认通过留白、对齐、渐隐和少量细线组织内容，必要框线保持可单独编辑。按 editable-layout.md 验证编辑操作、保存重开和打印；只标实际完成的测试通过。

## 1.1 独立验收门槛与返修判定
按实际交付类型选择必要的检查，但以下维度不得相互抵销：
- 证据：所有可核验数字、引文与资料版本；概念示意不得作为实测。
- 结构：产品几何、轮组数量、连接关系、视角与模型一致性，未知处标待核实。
- 空间：布局毫米坐标、图片区比例、冻结文字区和最终A3/其他尺寸的实际试排。
- 风格：项目视觉语言一致、主体突出、装饰和卡片边界适度。
- 局部保真：把原图与修改图对比；只改授权位置，不因整体观感更好而接受无关改变。
- 交付：图片真实像素、有效PPI、Alpha通道、可编辑文本、浏览器编辑能力、格式、印前出血/色彩要求。

检查结果为 pass / fail / untested / not_applicable；无证据或未验证时不能标pass。修复先分类：几何错误→可编辑布局；结构错误→原模型；局部错误→蒙版/图层；风格漂移→视觉适配；真实源像素不足→寻找原稿或重制。不得用不断重生成替代定位问题。

最终报告至少写：验证对象与版本、哪些项实测通过、哪些项失败/待验证、下一最小修复动作。无需为已通过维度再次重做。
