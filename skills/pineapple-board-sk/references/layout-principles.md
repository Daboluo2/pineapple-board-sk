# 展板排版原则与检查（1.1.1）

在③页面规划、⑦最终排版和⑧验收时读取；④视觉系统涉及字体、色彩与图像关系时按需读取。以下为产品设计展板的方法，不是赛事统一标准。以当前项目内容、展示方式和已确认约束为依据，不强制固定构图或数值比例。

## 1. 信息顺序与视觉层级
- 先明确核心信息：为谁、解决什么问题、通过什么方案；按已有证据表述，不为填标题编造价值或性能。
- 将内容分成首眼识别、继续理解和深入查阅三个阅读层次。说明主视觉、关键论点和支撑证据分别承担什么作用；不是强制三栏或三个模块。
- 按重要性分配空间、字号与对比。核心创新和关键证据应获得足够面积，不以素材数量或图片美观程度单独决定权重，也不平均分配所有模块。
- 模块标题尽量传达具体内容或有依据的结论。未验证的目标不能改写成已实现的结果。

## 2. 网格与构图
- 以边距、栏线、基线、间距和少量共享对齐线建立底层秩序；网格是定位工具，不必成为可见容器。
- 允许主图跨栏、图文穿插及非对称平衡，但不能遮挡文字、关键结构、图例或必要说明。精确位置仍以当前已确认的可编辑布局为准。
- 同级标题、图注及同类细节组保持一致；通过主辅尺度、位置、方向及疏密变化建立节奏，避免同宽、同高、同权重的重复区块。
- 多页保持字体、色彩语义、标注和间距体系连续，根据每页任务调整构图；不复制每页相同的装饰与模块位置。

## 3. 留白与分组
- 图注与对应图片、标注与对应部件相邻；不同主题间距要明显区别于组内间距。需要跨区关联时使用清晰编号或少量引线。
- 留白包括任意底色上的空区域，用于分组、停顿和突出主体。主图周边、标题区、正文区保留足够呼吸空间。
- 优先以距离、对齐和层级分区，再判断是否需要底色、框线或分隔线。留白量根据内容与用途调整，不规定统一百分比。

## 4. 图文分工
为计划使用的图片说明其解释任务，合并不增加信息的重复视角：

| 图像类型 | 主要问题 |
| --- | --- |
| 主效果图 | 产品是什么，整体形态和核心特征如何 |
| 场景图 | 谁在什么环境使用，情境与产品有什么关系 |
| 使用流程 | 如何操作，步骤与状态怎样变化 |
| 爆炸图或剖面 | 部件怎样组成，关键结构在哪里 |
| 局部特写 | 哪个细节值得注意，有什么有依据的作用 |
| 对比图或测试图表 | 比较什么，差异或结论有什么证据 |

不是每页必须具备所有图像类型。结构与动作未知时标待确认，不为满足图像分类制造内容。图表使用描述性标题、必要图例、单位与来源，图文共同回答问题；精确图表与文字保留可编辑。

## 5. 字体与色彩
- 建立标题、模块标题、正文和图注的角色层级；层级可由字号、字重、间距和位置共同建立，不要求每个角色换一种字体。
- 控制字体种类，同级内容样式一致；中文、英文与数字的字形、基线和标点在实际排版中检查。正文优先短句，避免拥挤长段。
- 字号、行距与行长根据最终物理尺寸、观看距离及文字量试排。放不下先精简或重排，不默认缩小字号。
- 不将细小文字压在复杂场景或低对比区域；可移动到已规划的干净排字区，或调整背景承载方式，不能因此侵占其他锁定区域。
- 强调色用于明确重点、步骤或部件，含义保持一致。类别、状态和对比同时提供文字、编号或形状提示，不仅靠红绿或其他颜色区分。

## 6. 根据内容选择构图
| 构图方法 | 适用条件 | 主要检查 |
| --- | --- | --- |
| 网格分栏 | 分类、比较或较多信息需要清晰组织 | 是否平均切块、缺少焦点 |
| 中心聚焦 | 整体形态或关键结构是主要论点 | 周围信息是否拥挤，顺序是否清楚 |
| 上部主图、下部分解 | 先展示整体，再解释细节 | 下部是否挤压正文与图注 |
| 非对称 | 主辅关系明确，需要视觉节奏 | 两侧视觉重量是否失衡 |
| 曲线或斜向 | 形态、动作、流程或主题具有方向性 | 是否切碎内容、浪费空间或妨碍阅读 |

选择时简要说明与本页内容的关系，不必固定数量或每次输出全部选项。Z型、F型可作分析视角，不是强制阅读路径；网页眼动结论不能直接当作印刷展板的观看证据。用焦点、层级、分组与必要编号明确实际顺序。

### 避免矩形堆叠：具体约束，不替代以上原则
- 不默认采用逐模块矩形卡片、等尺寸图片墙或一排排独立底板。无边框的等大模块仍可能是机械堆叠，需要检查主次、疏密和关联关系。
- 矩形可以用于真实照片、对比、表格、必要的阅读底色或明确选择的布局。保留应有内容与可读性，不为了无框强行抠图、渐隐或裁掉结构。
- 不能只是把矩形换成圆形、多边形继续等权堆叠。异形、跨区和穿插同样需要服务信息任务，不把形状数量当作质量指标。
- 连续背景与隐形网格可以保持整体感；有意的分区边界应具有明确用途。已确认布局若需实质调整，遵循当前项目确认方式，不借本原则悄然改版。

## 7. 按最终输出检查
按实际交付范围执行并记录结果，不把建议当作已测试结论：
1. 缩略图：主视觉与核心信息是否突出，视觉重量和疏密是否合理。
2. 阅读顺序：仅看标题与主图能否理解项目大意，各区关系是否明确；需要验证理解效果时让他人试读，未试读不声称用户验证通过。
3. 最终尺寸：检查正文、图注、引线、对比与细节；缩略预览不能替代实际尺寸检查。
4. 图文对应：说明是否能找到对应图或部件，图片是否提供新增信息，图表是否有必要标识和证据。
5. 文件输出：核对尺寸、方向、页数、有效清晰度、裁切、字体及接收方要求。参考 review-output.md 记录 pass / fail / untested / not_applicable。

问题按来源修正：层级混乱回到信息优先级；空间拥挤回到文案与布局；图像重复回到素材计划；对比不足调整样式；图像或结构错误回到对应素材。修改后只复查受影响部分。

## 来源及适用边界
以下来源支撑层级、网格、分组、图文解释和输出检查；本文件中的产品图像分工及构图选择表是面向展板的归纳，不是来源中的统一规范。资料检索日期：2026-10-26。
- [Adobe：What makes a great layout?](https://www.adobe.com/learn/illustrator/web/layout-basics)：焦点、层级及版式基础。
- [IBM Design Language：Tips and techniques](https://www.ibm.com/design/language/layout/tips-and-techniques/)：重复与变化、留白、动线和非对称。
- [NN/g：5 Principles of Visual Design in UX](https://www.nngroup.com/articles/principles-visual-design/)：尺度、层级、平衡、对比及分组；来自UX语境，应用于展板须结合媒介判断。
- [UC Berkeley：Poster Design](https://guides.lib.berkeley.edu/posters/design)：视觉解释、图例、逻辑顺序及可读性；学术海报的栏目和字号不直接套用到设计竞赛展板。
- [Purdue：Tips for Creating Posters](https://guides.lib.purdue.edu/c.php?g=799769&p=5716387)：最终尺寸、字体控制、对比、对齐、输出质量；具体字数及分辨率建议不是所有项目的硬阈值。
- [NN/g：F-Shaped Pattern of Reading](https://www.nngroup.com/articles/f-shaped-pattern-reading-web-content/)：澄清F型并非唯一网页扫描模式，不推导为展板固定路径。
- 用户提供的[展板案例文章](https://mp.weixin.qq.com/s/glZWByhTgKg6k0eDI2L8ZQ)和[排版与构图技巧](https://mp.weixin.qq.com/s/eGHojo4cTJs5J9dITEK4sg)：作为案例与构图线索；首次案例阅读仅含本地可用的11张正文配图，不宣称看完全部案例，也不凭文章标题确认每个案例的获奖状态。

不将“评委只有30秒”、固定主图比例、统一字号、固定留白比例或特定背景色写成普遍定律。赛事与印刷要求在实际项目中另行核实。
